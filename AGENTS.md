# Extreme Sudoku

Это проект генератора и веб-приложения для экстремально сложных Sudoku.

## Документация

Перед работой обязательно изучи соответствующую спецификацию:

- Общая концепция проекта: `docs/PRODUCT_SPEC.md`
- Frontend: `docs/UI_SPEC.md`
- Генератор Sudoku: `docs/GENERATOR_SPEC.md`
- Формат обмена данными: `docs/DATA_FORMAT.md`

## Важные правила

- Не изменяй архитектуру без необходимости.
- Генератор и frontend должны оставаться независимыми.
- Backtracking разрешён для проверки решения и уникальности.
- Backtracking запрещён для оценки человеческой сложности Sudoku.
- Все новые техники Human Solver должны иметь unit-тесты.
- Перед реализацией генератора прочитай `docs/GENERATOR_SPEC.md`.
