# Иллюстрированная справка по стратегиям

Справка содержит девять приёмов: последняя пустая клетка, единственный кандидат, единственное место для цифры, Pointing, Claiming, открытая пара, скрытая пара, X-Wing и XY-Wing. Каждый урок состоит из трёх шагов: условия, объяснение, результат. Русские объяснения, наборы кандидатов и схемы составлены специально для проекта.

Это статические учебные схемы, а не задачи для игры и не подсказки к текущему полю. Они не обращаются к генератору, решателю, результатам игрока или хранилищу. Серые клетки не показаны и не задают ограничений. Для Pointing, Claiming и X-Wing показана только выбранная цифра; отсутствие этой цифры в показанной клетке не означает отсутствие остальных кандидатов. В остальных схемах наборы кандидатов показанных пустых клеток полные, кроме исходных клеток двух вводных уроков, где кандидаты ещё предстоит определить.

## Контракт данных и проверка

`web/lib/strategy-content.js` экспортирует `STRATEGY_INTRO` и массив `STRATEGIES`. Каждый шаг содержит самостоятельный снимок диаграммы: клетки, области, стрелки, исключения и найденные цифры. Индексы клеток — от 0 до 80, областей — от 0 до 8. Исключённые цифры сохраняются в исходном наборе кандидатов и помечаются через `eliminations`; найденные значения задаются через `value` и `placements`. Режим `candidateMode: 'digit'` с `digit` явно отличает отображение одной цифры от полного набора кандидатов.

`web/tests/strategy-content.test.js` проверяет контракт всех 27 снимков и логические выводы независимо от формулировок уроков. Для скрытой одиночки и пар перебираются допустимые назначения показанной полной области; для Pointing, Claiming и X-Wing — все размещения выбранной цифры в исходных областях. Для XY-Wing проверяются оба значения центральной клетки и видимость обоих крыльев. Проверки не утверждают уникальность или полноту решения целой сетки: для локальных выводов достаточно показанных условий.

Негативные контрпримеры подтверждают необходимость условий: дополнительное место в исходной строке X-Wing, третий кандидат открытой пары, внешнее место цифры скрытой пары и клетка, видящая только одно крыло XY-Wing. Тестовый перебор ограничен учебными схемами и не используется для оценки человеческой сложности.

Проверка: `node --test web/tests/strategy-content.test.js` — 14 тестов, все пройдены 9 октября 2026 года. Общая проверка интерфейса и браузерные сценарии выполняются отдельно.
